# 🚗 자동차 경주 (Racing Car Game)

> 우아한테크코스 프리코스 2주 차 미션  
> 여러 역할을 수행하는 큰 함수를 단일 역할의 작은 함수로 분리하고, 테스트 도구를 활용하여 프로그램의 정확성을 검증한다.

---

## 📚 학습 목표

- 여러 역할을 수행하는 함수를 단일 역할의 작은 함수로 분리한다.
- JUnit5와 AssertJ를 사용하여 프로그램이 올바르게 작동하는지 테스트한다.
- 1주 차 공통 피드백을 반영해 코드 품질을 개선한다.

---

## 🚀 과제 진행 방식

1. **저장소 포크 및 클론**
    - 제공된 자동차 경주 저장소를 포크(fork) 후 로컬로 클론(clone)한다.

2. **기능 목록 작성**
    - 기능 구현 전 `README.md`에 기능 목록을 정리해 추가한다.

3. **단위별 커밋**
    - 각 기능 단위로 커밋을 진행한다.
    - 커밋 메시지는 [AngularJS Commit Message Conventions](https://github.com/angular/angular.js/blob/master/DEVELOPERS.md#commits)을 따른다.

4. **제출**
    - 구현 완료 후 GitHub PR 링크를 우아한테크코스 지원 플랫폼에 제출한다.

---

## 🧩 기능 요구 사항

- **입력**
    - 경주할 자동차 이름을 쉼표(,) 기준으로 구분 입력받는다.
    - 각 자동차 이름은 **5자 이하**이어야 한다.
    - 시도할 횟수를 입력받는다.

- **동작**
    - 주어진 횟수 동안 자동차는 전진하거나 멈출 수 있다.
    - 0~9 사이의 랜덤 값을 구한 뒤, **4 이상일 경우 전진**한다.
    - 전진한 자동차의 상태를 이름과 함께 출력한다.

- **출력**
    - 매 시도별 실행 결과를 출력한다.
    - 모든 시도 종료 후 **최종 우승자(복수 가능)**를 출력한다.
    - 공동 우승 시 쉼표(,)로 구분하여 출력한다.

- **예외**
    - 잘못된 입력 시 `IllegalArgumentException`을 발생시키고 프로그램을 종료한다.
